# Magics Project Brief

## Project Overview
Magics is a Rust implementation of a multi-agent path planning system using Gaussian Belief Propagation (GBP) for robotic navigation in complex environments. The project is now being extended with a Python API to enable reinforcement learning research through OpenAI Gym integration.

## Core Requirements
1. Simulate multiple robots navigating through complex environments
2. Implement Gaussian Belief Propagation algorithm 
3. Avoid collisions between robots and obstacles
4. Support dynamic and flexible path planning
5. Provide visualization and analysis tools
6. Enable external control via Python API
7. Support integration with reinforcement learning frameworks

## Key Features
- Multi-agent path planning
- Collision avoidance
- Configurable simulation scenarios
- Performance-optimized Rust implementation
- Flexible factor graph architecture
- Support for various environment types
- PyO3-based Python bindings
- OpenAI Gym environment integration
- Step-based simulation control

## Project Scope
- Develop a robust simulation framework
- Implement GBP algorithm from scratch in Rust
- Create multiple scenario configurations
- Provide performance metrics and visualization
- Expose simulation state to external Python code
- Enable reinforcement learning research on path planning
- Support per-agent factor graph weight modification

## Success Criteria
- Successful navigation of multiple robots
- Minimal collision rates
- Efficient computational performance
- Flexible and extensible codebase
- Comprehensive documentation and analysis tools
- Functioning Python API with OpenAI Gym compatibility
- Ability to control simulation step-by-step
- Support for both system-wide and per-agent factor graph weights

## Research Context
Master's Thesis Project in Computer Engineering at Aarhus University, focusing on advanced multi-agent path planning techniques with applications to reinforcement learning research.
